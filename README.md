## 🎮 Project Overview

This project explores the implementation of a parry mechanic in a third-person action game using Unreal Engine and C++.

The goal is to develop and understand the gameplay logic behind parrying while using debugging tools to inspect behavior during development.

This project also serves as an opportunity to improve my Unreal Engine C++ programming skills and explore how individual combat mechanics can be developed, tested, and refined.

---

## ⚔️ Features

- **Third-Person Action Gameplay:** A third-person gameplay foundation for testing combat mechanics.
- **Parry Mechanic:** A combat mechanic focused on defensive timing and interaction.
- **Debugging Support:** Development tools and workflows to help inspect and understand the parry system.
- **C++ Implementation:** Gameplay programming using Unreal Engine's C++ framework.

---

## ⚙️ Core Systems

### Parry System

The central focus of the project is the parry mechanic.

This system is intended to provide a foundation for testing defensive combat interactions and refining how parrying behaves during gameplay.

### Debugging and Testing

Debugging is an important part of the project, helping make the combat mechanic easier to inspect and troubleshoot during development.

This supports iterative testing as the system is adjusted and improved.

### Third-Person Gameplay

The project uses a third-person action-game setup to provide a context for developing and testing the parry mechanic.
